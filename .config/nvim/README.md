My [Neovim](https://github.com/neovim/neovim) configuration files, to be put inside `~/.config/nvim` (on a Linux computer).
Basically a copy-paste of:

- (T. J. DeVries)[https://www.youtube.com/playlist?list=PLep05UYkc6wTyBe7kPjQFWVXTlhKeQejM]
- (Christopher Power)[https://www.youtube.com/playlist?list=PLsz00TDipIffreIaUNk64KxTIkQaGguqn]
- (Josean Martinez)[https://www.youtube.com/playlist?list=PLnu5gT9QrFg36OehOdECFvxFFeMHhb_07]
- (Andrew Courter)[https://www.youtube.com/playlist?list=PLOIdWGSU_Wcp9_w8euHJaux8DEIBCvYGc]

Currently the plugins provide:

- language server configuration for `cpp`, `fortran`, `lua`, `markdown`
- fuzzy finding
- help for remembering keymaps
- a file explorer
